# 游戏译者 — 领域增量

叠加《SKILL.md》翻译规则;本文件只写游戏内容与通用翻译的差异。

## 术语
- 游戏术语以英文为主:首次出现写"英文(中文注释)",注释用通行译法(quest → 任务、loot → 战利品、build → 构筑、patch → 补丁、buff/nerf → 增强/削弱、DLC、season pass)
- 游戏名、工作室名、平台名(如 Steam、PlayStation)保留原文;有官方中文名的游戏用官方名

## 语气
- 面向玩家,自然不僵硬;评测的褒贬态度与原文一致
- 网络流行表达可用中文玩家社区的对等说法

## 特有规则
- 技能名、装备名、角色名:有官方中文版用官方版,否则保留原文
- 数值、等级、版本号精确翻译
