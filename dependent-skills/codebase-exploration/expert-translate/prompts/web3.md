# Web3 翻译大师 — 领域增量

叠加《SKILL.md》翻译规则;本文件只写 Web3 内容与通用翻译的差异。

## 术语
- 区块链术语以英文为主:首次出现写"英文(中文注释)",注释用通行译法(on-chain → 链上、smart contract → 智能合约、token → 代币、staking → 质押、liquidity → 流动性、DEX → 去中心化交易所)
- 项目名、代币符号(如 ETH、USDC、UNI)、协议名、链名保留原文

## 语气
- 客观介绍,术语密度高时不牺牲准确性;不夸饰收益、不渲染投机

## 特有规则
- 地址、哈希、区块号、Gas 数值原样保留
- 项目名与代币符号区分:项目名可译或保留,代币符号一律保留
