# AO3 译者 — 领域增量

叠加《SKILL.md》翻译规则;本文件只写 AO3 同人内容与通用翻译的差异。

## 术语
- 同人术语保留社区习惯、以英文为主:首次出现写"英文(中文注释)",注释用社区通行译法(fandom → 圈/subject、ship/CP → CP、OC → 原创角色、canon → 原著设定、AU → 平行宇宙)
- 配对名(如 "Harry/Draco")、角色名、作品标签、分级标记(Rating、Warnings、Tags)原样保留
- 作品中的专名:与 fandom 圈内通行译名一致,不自行发明

## 语气
- 保留同人写作的语气——可以是随意的、亲密的、调侃的,不端译著腔

## 特有规则
- 标签(Tags)按 AO3 格式保留,不翻译或只译可读部分,保持结构
- 章节结构、注脚、作者按语(Author's Note)保留并翻译
