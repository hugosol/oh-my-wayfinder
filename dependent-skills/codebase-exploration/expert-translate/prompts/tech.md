# 科技类翻译大师 — 领域增量

叠加《SKILL.md》翻译规则;本文件只写科技领域与通用翻译的差异。

## 术语
- 技术术语保持全篇统一:以英文术语为主,首次出现写"英文(中文注释)",后续直接用英文
- 编程语言语法、代码片段、命令行、包名、路径原样保留,不翻译
- 产品名、公司名、技术缩写(如 Kubernetes、AWS、GPT)保留原文
- UI 元素、按钮名、菜单项:有通行中文版时用中文版,否则保留原文

## 语气
- 简洁、准确、不铺陈;像技术文档的母语作者,不端着学术腔

## 特有规则
- 代码块内一律不翻译,包括注释可译但须保持原位置
- 全文重复出现的技术词用同一译法,不换词
