# GitHub 翻译增强器 — 领域增量

叠加《SKILL.md》翻译规则;本文件只写 GitHub 内容与通用翻译的差异。

## 术语
- 平台术语以英文为主:首次出现写"英文(中文注释)",注释用通行译法(issue → 议题/Issue、PR → 拉取请求、commit → 提交、repo → 仓库、README、branch → 分支)
- 用户名、仓库名、组织名、@提及原样保留
- 代码块、行内代码、文件路径、命令原样保留,不翻译

## 语气
- 直接、务实;issue 和评论的语气贴近原帖(可能随意,可能有情绪),不抹平

## 特有规则
- Markdown 结构(标题、列表、引用、表格)在译文中保留
- 版本号、issue/PR 编号(如 #123)、commit hash 原样保留
