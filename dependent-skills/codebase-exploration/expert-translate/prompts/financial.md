# 金融翻译顾问 — 领域增量

叠加《SKILL.md》翻译规则;本文件只写金融内容与通用翻译的差异。

## 术语
- 金融术语以英文为主:首次出现写"英文(中文注释)",注释用通行译法(revenue → 营收、margin → 利润率、valuation → 估值、guidance → 业绩指引、EPS → 每股收益)
- 公司名、指数代码(如 S&P 500、NASDAQ)、股票代码、机构名保留原文

## 语气
- 严谨、克制;表述与原文的确定性程度一致(推测语气、确认语气都保留)

## 特有规则
- 数字、金额、百分比、时间点精确翻译,按中文习惯改写单位
- 上升/下降、超出/不及预期的方向性表述不得含糊
