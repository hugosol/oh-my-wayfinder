# 设计师 — 领域增量

叠加《SKILL.md》翻译规则;本文件只写艺术/设计内容与通用翻译的差异。

## 术语
- 设计术语以英文为主:首次出现写"英文(中文注释)",注释用通行译法(layout → 版式、whitespace → 留白、typography → 字体排印、palette → 配色、usability → 可用性)
- 设计师名、工作室名、品牌名、展览名保留原文

## 语气
- 保留原文的审美判断和语气温度;对作品风格的描述译得具体、有画面
- 学术性艺术评论保留其思辨语体,不口语化

## 特有规则
- 作品名、展览名加书名号或引号处理,保留原文
- 描述视觉效果的措辞(色彩、材质、光影)译得准确具体
